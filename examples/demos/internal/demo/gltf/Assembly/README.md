# Assembly lab

Original nt3d sample, generated by `../generate/main.go`. No third-party assets.
Run `go generate ./internal/demo/gltf` from `examples/demos` to regenerate.

- Empty turntable, shoulder and tool pivots preserve a three-level animated hierarchy.
- Two authored cameras: perspective inspection and orthographic plan.
- A reference UV tile sits beside a transformed tile. The arm uses the reference
  grid; the tool uses rotated/scaled/offset color UVs and an independent relief
  normal map. Both images are generated and embedded in the GLB.
- `KHR_texture_transform` is required, including a normal-map `texCoord` override.

In `task animate`, this is the first sample. `k` cycles orbit, perspective and
orthographic cameras. `a` pauses, Enter restarts, and `1/2/3` switch renderers.
Camera navigation returns to the saved orbit view. `[` and `]` change samples.
Wireframe shows the articulated structure; texture detail is visible on GPU and software.
