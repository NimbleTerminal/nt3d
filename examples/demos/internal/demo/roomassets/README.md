# Lighting-room fixtures

These original synthetic Radiance RGBE files are generated by `generate.py` and
shipped with the demo. They require no downloads or baking during rendering.
They illustrate **consuming** externally supplied textures, not a GI solution.

- `room.hdr`: a panorama authored from a box interior at `(0, 0, 1)`, with warm
  and cool panels and stripes on the wall removed by the cutaway view.
- `floor.hdr`, `wall.hdr`: hand-authored linear irradiance fields (before albedo
  and division by pi). The floor includes fixed pedestal contact darkening.

The moving sphere is intentionally absent from these static fixtures. There is
no dynamic capture, indirect tracing, or moving-object lightmap update.
Replace these files with your own exported irradiance atlases and matching UVs
for a production bake. Run `python3 generate.py` to reproduce the bundled files.
