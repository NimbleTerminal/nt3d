Fur

ShapesModelsDense meshSource ↗

Shell fur on Spot the cow (by Keenan Crane, public domain): the mesh drawn again in layers, each pushed out along the normals and cut to the strands’ cross-section by one shared texture, whose alpha is each strand’s height, at the layer’s own threshold. Spot’s own texture colors the fur, and the wind moves each layer’s node, so swaying uploads no geometry.
