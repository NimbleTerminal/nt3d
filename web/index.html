One scene, three renderers.

Press 1 for GPU, 2 for software, or 3 for wireframe. GPU rendering falls back to software when unavailable.

Prefer a native terminal?

From the repository, run task terrain, task procedural, task dynamic, task shapes, task models, or task large in Kitty, or task meshes -- model.stl for your own files. Use --help for options.
